B.1: Harris Corner Detection

Implementation of Harris Interest Point Detector with Adaptive Non-Maximal Suppression (ANMS) for robust corner detection and feature selection.

Harris Corner Detection

The Harris corner detector identifies interest points by analyzing the local image structure. Our implementation uses the provided harris.py code with scikit-image's corner detection algorithm.

  • Single Scale Detection: Uses sigma=1 for consistent corner detection
  • Edge Discarding: Removes corners within 20 pixels of image boundaries
  • Peak Detection: Uses local maxima with minimum distance constraints

Adaptive Non-Maximal Suppression (ANMS)

ANMS selects the most distinctive corners while ensuring good spatial distribution. Our implementation:

  • Response Sorting: Orders corners by Harris response strength
  • Distance Filtering: Maintains minimum 30-pixel separation between corners
  • Quality Selection: Chooses top 100 corners with optimal spacing

B.2: Feature Descriptor Extraction

Implementation of 8x8 feature descriptor extraction with bias/gain normalization for robust feature representation and matching.

Feature Descriptor Implementation

Our feature descriptor extraction follows the paper's specifications for creating distinctive, normalized descriptors from detected corners:

Key Features:

  • 40x40 Sampling Window: Large window around each corner for comprehensive feature capture
  • Gaussian Blurring: 5x5 Gaussian filter to reduce noise and aliasing
  • 8x8 Downsampling: Linear interpolation to create 8x8 patches
  • Bias/Gain Normalization: Zero-mean, unit-variance normalization for robustness

Normalization Process

The descriptors undergo robust normalization to ensure consistent feature representation:

  • Mean Subtraction: Removes bias (illumination differences)
  • Standard Deviation Normalization: Ensures unit variance (contrast invariance)
  • Robust Filtering: Skips nearly-constant patches (std < 1e-5)

B.3: Feature Matching

Implementation of feature matching using Lowe's ratio test to find corresponding features between image pairs for robust homography estimation.

Feature Matching Implementation

Our feature matching algorithm uses the improved Lowe's ratio test to find reliable correspondences between feature descriptors from different images:

Key Features:

  • Lowe's Ratio Test: Compares first and second nearest neighbor distances
  • Adaptive Thresholding: Uses ratio threshold of 0.6-0.8 for optimal balance
  • Distance Filtering: Additional constraints on minimum and maximum distances
  • Duplicate Removal: Ensures bidirectional consistency in matches

Matching Algorithm

The matching process follows these steps:

  • Descriptor Comparison: Compute Euclidean distances between all descriptor pairs
  • Nearest Neighbor Search: Find first and second nearest neighbors for each descriptor
  • Ratio Test: Apply Lowe's test: distance1 < ratio_threshold × distance2
  • Quality Filtering: Remove matches that are too close or too far

B.4: RANSAC for Robust Homography

Implementation of 4-point RANSAC for robust homography estimation using OpenCV's proven RANSAC algorithm combined with Part A mosaicing code for seamless automatic image stitching.

RANSAC Implementation

Our B.4 implementation uses OpenCV's robust RANSAC algorithm to estimate homography matrices, filtering out outliers and ensuring reliable transformations:

Key Features:

  • OpenCV RANSAC: Uses proven cv2.findHomography with RANSAC method
  • Robust Estimation: Filters outliers using distance threshold of 8.0 pixels
  • Inverse Homography: Correctly computes inverse homography for proper image warping
  • Part A Integration: Uses proven Part A mosaicing code for blending
  • Fully Automatic: No manual point selection required

Automatic Mosaicing Pipeline

The implementation combines B.1-B.3 feature detection with robust RANSAC homography estimation:

  • B.1: Harris corner detection with ANMS for feature selection
  • B.2: 8x8 feature descriptor extraction with bias/gain normalization
  • B.3: Feature matching using Lowe's ratio test
  • B.4: OpenCV RANSAC for robust homography estimation
  • Part A: Proven mosaicing code for image warping and blending
